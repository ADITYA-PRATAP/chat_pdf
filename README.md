# 📚 AI Q&A System with PDF Support

A modern, AI-powered Question & Answer system that supports querying PDF content in real time. Built with **Next.js 15**, **OpenAI**, **Clerk**, and **Pinecone**, this application provides seamless **chat-based interactions**, **vector search**, and a sleek **UI** powered by **ShadCN UI** and **Radix UI**.

---

## 🚀 Tech Stack

### 🖥️ Frontend
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **UI**:
  - [Radix UI](https://www.radix-ui.com/)
  - [ShadCN UI](https://ui.shadcn.dev/)
  - [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: React Query
- **Authentication**: Clerk
- **Streaming AI Responses**: Vercel AI SDK

### 🗄️ Backend
- **Database**: [NeonDB](https://neon.tech/) for persistent storage
- **Vector DB**: [Pinecone](https://www.pinecone.io/) for semantic search
- **ORM**: Drizzle ORM
- **File Storage**: AWS S3
- **Payments**: Stripe
- **AI Integration**: OpenAI SDK
